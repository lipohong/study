## 一個相連的系統

```text
外部資訊 -> 建立和提取世界模型（知識）
-> 解釋、預測和修訂相關關係（理解）
-> 在特定條件下練習 -> 穩定完成任務（能力）
-> 檢視結果和回饋 -> 修訂模型和策略（學習）
-> 跨任務改善獲取和修訂的循環（學習能力）
```

這是一個循環，不是每項任務都必須依次走完每一階段的流程。閱讀、觀看和記憶可以幫助學習，但接觸內容和熟悉感本身不能證明理解、表現或遷移。

| 概念 | 工作定義 | 有用的檢查 |
|---|---|---|
| 資訊 | 可供使用的外部符號、數據和描述。 | 收到了甚麼？來自哪裏？ |
| 知識 | 有合理支持、可提取、可修訂的內在模型，包含事物、關係、條件和程序。 | 我能用甚麼解釋或預計一個個案？ |
| 理解 | 已展示能運用相關模型關係，包括解釋、條件式預測、邊界檢驗或修訂。 | 我能解釋原因，處理改變了的個案嗎？ |
| 學習 | 經驗及回饋後，能提取、推論或做到的事情出現相對持久的改變。 | 過一段時間再試，有甚麼不同？ |
| 能力 | 在已指明條件下，對一類已界定任務作出相對可靠的表現。 | 我能獨立、重複地做到嗎？ |
| 學習能力 | 隨任務而變、有效獲取、檢驗、修訂和遷移模型及技能的能力。 | 我能診斷瓶頸，改善下一次嘗試嗎？ |

## 知識是可用的模型

知道在標準大氣壓下水約於 100 °C 沸騰，是有用的事實。更有連結的模型亦把氣壓與沸點連起來，因此能預測高海拔的沸點較低。預測有適用條件；這些例子不能推出一個事實或模型可以解釋所有個案。

稱知識為**對規律的壓縮**，強調少量關係可以組織許多觀察。但單是壓縮並不足夠：簡潔卻錯誤的規則不是好知識。要問模型有甚麼支持、適用於哪裏、能解釋或預測甚麼、甚麼情況需要修訂。筆記和 LLM 回應仍是外部資源，直到學習者能提取和使用相關關係。

## 學習改變日後的運用，不只是接收內容

觀看游泳教學是輸入；在已指明條件下安全游泳，才是表現證據。兩者之間可能需要建立初步模型、練習、發現錯誤及調整。可用的循環是：

1. 說出問題、目前猜測、關係及其條件。
2. 查閱合適資源，把新概念連到已有知識。
3. 合上資料，用自己的話提取或解釋關係。
4. 做一項代表性任務，再試一個變例；記錄結果。
5. 找出最早失效的假設、缺少的程序或不合適的策略。
6. 修訂最小的受影響部分，再試一次，並於稍後檢查。

改變可以是新關係、範圍較窄的規則、更好的程序，或更可靠的提取。只是重複修正後的句子，不足以證明舊錯誤不會在新個案重現。

## 能力與學習能力

寫作能力不是寫作技巧清單。在已界定情境中，它涉及理解讀者、選擇和組織資訊、起稿、察覺弱點，以及按準則修改。證據是在相關限制下重複完成作品，不是自稱知道怎樣寫。

學習能力不等於記憶力，也不是一個固定的通用「引擎」。它涉及多項互相作用、可以改進的做法：

| 環節 | 可觀察行動 |
|---|---|
| 找出問題 | 說清楚缺少甚麼，不只說「我不會」。 |
| 選擇資源 | 選用相關、可信的例子、教學或回饋。 |
| 抽象 | 從多個例子提取關係，同時保留適用條件。 |
| 理解 | 解釋各部分如何相關，並預測變例。 |
| 提取 | 不靠頁面的熟悉感，回想有用的關係。 |
| 實踐 | 實際完成目標任務，不只閱讀介紹。 |
| 運用回饋 | 分清模型錯誤、提取失敗、策略不合和執行失誤。 |
| 遷移 | 檢驗關係在新場景是否仍然適用，指出其界線。 |

不同任務需要不同組合。在一個領域學得快，或只比較兩個學習者一次，都不足以判斷一個人的整體學習能力。

## 具體如何改善

針對一項目前的子技能，先定義表現目標，不看筆記嘗試，找出一個瓶頸。選一項針對性的做法：例如學習者看懂教程中的程式迴圈，隔天卻無法自己寫出時，可嘗試提取並取得回饋。用即時任務和延遲的變例檢驗；若結果沒有改善，先檢視診斷、題目難度及策略，再決定是否重複同一種輸入。

白話教回可以暴露含糊的關係：**它是甚麼？為甚麼有效？有甚麼例子？跟相近概念有甚麼不同？** 流暢解釋是有用檢查，並非證明；再加入不看筆記的預測或應用。以機會成本為例，問把三小時用於手機、選擇某公司項目，或繼續升學時，放棄了甚麼。要檢查最有關係的最佳替代選擇及條件，而不只背定義。

把新概念連到已有模型，往往更容易使用，但連結也可能帶進舊錯誤。要問哪些地方可以沿用，類比又在哪裏失效。沒有一種學習方法保證適合所有任務；可比較準確度、獨立性、延遲表現和遷移。有限定條件的研究例子見[與學習條件相關的實驗證據](/zh-hant/sources/study-conditions-experimental-evidence/)。

## 證據界線及下一步

本文記錄一套偏好的解說和檢驗學習方式，不代表學習者已掌握六項區分，也不代表已量得學習速度改善。最小下一步是不看筆記完成[診斷及改進學習能力](/zh-hant/practice/drills/learning-ability-diagnosis/)：找一個瓶頸、選一項做法，並訂出即時及延遲檢查。
