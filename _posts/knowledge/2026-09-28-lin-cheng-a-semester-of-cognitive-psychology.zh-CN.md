# 一個學生深入學習認知心理學的故事

人物、對話、課堂事件與學習結果均為虛構。文中涉及的研究另列來源；人物的進步用來示範學習過程，不代表照做就會得到相同成效。這是一學期開始深入一門學科的故事，重點放在注意、記憶與後設認知，再延伸到推理、遷移與合作。

林澄第一次選修認知心理學，是因為一件讓他困擾很久的事。

他讀書時，常覺得作者講得很清楚。合上書，內容卻散了；遇到換了情境的題目，更不知道該用哪個概念。

他想知道：「這是記憶不好，還是我其實沒有理解？」

林澄的學習能力向來不錯。他會主動找例子、向別人請教，也願意重做失敗的題目。但認知心理學仍讓他卡住了。這次，他決定把自己的學習過程也留下記錄。

**開學第三天，他先讓自己的困惑變得可以檢查。**

讀完記憶章節後，他預估自己能答對八成問題。周老師請他關上書，回答三道題：工作記憶與長期記憶有什麼關係？怎樣設計研究，檢查重讀與回想哪種方法更有助於一週後記憶？一個人能背出定義，卻判斷錯誤的例子，可能卡在哪裡？

林澄說出了幾個名詞，後面就停住了。他對第一題的解釋一直繞回原來的定義；第二題沒有控制學習時間；第三題只會說「理解不夠深」。

他有點難堪，差點在筆記上寫下「我的理解能力很差」。寫到一半，他停筆了。

「這句話沒有告訴我明天要改什麼。」

他改成：「我目前能認出名詞，但不能獨立解釋關係，也不會用證據區分幾種可能原因。」

這時，他開始把「問題」理解為具體的差距：目前能做到什麼、希望做到什麼、障礙可能在哪裡。對自己的評語，變成了可以著手處理的任務。

他替學期末訂下四個目標：能說明學科主要領域之間的關係；能用概念分析陌生案例並指出適用邊界；能讀懂幾篇原始研究的設計與推論；能和同學合作，設計並檢查一個學習方案。

他每週安排三次九十分鐘學習，另用三十分鐘檢查進度。時間是他能持續負擔的安排，之後可以修改。

**第一週，他先畫出學科的地圖，然後選擇深入的入口。**

他翻閱課本目錄與大學公開課程，把知覺、注意、記憶、語言、概念、推理與問題解決放在紙上。這些確實也是認知心理學課程常見的研究領域。[1]

起初，紙上只有名詞。林澄試著用「讀懂一篇論文」把它們連起來：辨認文字涉及知覺；選擇目前要處理的內容涉及注意；理解句子需要語言知識；把前後句連起來，需要暫時維持相關資訊；判斷作者的結論，還要運用既有知識與推理。

他在旁邊註明：「這是分析同一活動的不同角度，各過程可能互相影響，不能把箭頭當成大腦唯一的工作順序。」

接著，他選定「為什麼看懂後仍用不出來」作為深入入口，集中研究注意、記憶與後設認知（也稱元認知），也就是人如何監察與調整自己的認知活動。其他領域保留基本學習，避免把一門學科縮成幾個讀書技巧。

第一次讀論文時，他又遇到瓶頸：不懂自變項、依變項與隨機分派。他花了一次學習時段，補上研究方法的基礎，再回到原文。

他在日誌寫道：「讀不懂這篇論文的其中一個原因，是我缺少分析實驗的工具。今天先補這一塊。」

這是學習能力的一個具體表現：能辨認當下缺少的條件，重新安排學習，而不是讓原定進度一直推著自己走。

**第二週，他發現，背得出定義之後，還有許多事沒有理解。**

他讀到工作記憶，先記下常見的工作定義：「在當前活動中，暫時維持並處理資訊的功能。」

為了檢查理解，他做了兩件小事：心算二十七加十八，並閱讀一句前後關係較複雜的句子。他試著辨認，哪些資訊需要暫時保留，哪些步驟需要處理，以及哪些知識是從長期記憶中調用的。

他對同學解釋：「做心算時，我需要暫時保留中間結果，也要使用早已學會的加法知識。這讓我看見，暫時處理與長期知識可以在同一任務中合作。」

他想用「桌面和書櫃」作比喻，隨即補上一句：「這個比喻只幫助區分目前使用的資訊與較長期的知識。它不能證明大腦裡有兩個這樣的實體容器。」

後來，他讀到工作記憶有不同理論模型。Baddeley 對多成分取向的討論，也區分整體理論框架與較具體的模型，並涉及其他取向。[2]

林澄開始把筆記分成三種內容：觀察到了什麼；模型怎樣解釋；哪些地方仍有爭議。遇到課本上的方框與箭頭，他會問：「支持這條關係的證據是什麼？」

他也養成一個習慣：每學一個概念，都寫下定義、一個具體例子、容易混淆的鄰近概念，以及一個尚未回答的問題。

例如，他現在可以問：「如果兩個任務一起做時表現變差，是否只有『使用同一資源』這一種解釋？切換、策略改變或其他干擾是否也可能造成結果？」

他的理解，開始表現在能提出有區別的問題，並看見需要什麼證據。

**第三週，一篇研究讓他把過於簡單的結論改掉了。**

林澄讀到 Roediger 與 Karpicke 的研究：學生閱讀短文後，有人重讀，有人進行回想測驗；研究者在不同時間測量保留情況。在這些實驗中，五分鐘後的測驗可以出現重讀的優勢，兩天或一週後的測驗則出現先前回想的優勢；反覆閱讀也提高了學生對自己記憶的信心。[3]

他原本想寫：「測驗永遠比讀書有效。」讀到測量時間不同、結果也不同，便把這句劃掉。

他重新寫道：「判斷方法是否有效，必須說清楚學什麼、怎樣練、隔多久測，以及測的是什麼表現。」

接著，他用三次閱讀處理論文。第一次只找研究問題與比較條件；第二次核對方法和結果；第三次檢查作者的解釋，以及是否存在其他可能。

他在論文旁寫了兩行：「觀察到提取練習的效果」與「確定效果完全由某一機制造成」，需要不同強度的證據。

這時，「知識」對他有了更具體的含義：某個說法值得相信到什麼程度，要能追溯它的根據。他可以合理採用一個已有支持的方法，同時保留對機制與適用範圍的疑問。

理解規律的練習，也變成了具體動作：把「通常有效」展開成條件、比較、結果與邊界，然後尋找可能改變結論的情況。

**第四週，他把學到的內容用來修改自己的學習。**

以前，林澄讀完一節就再看一遍。現在，他先讀一小段，合上書，重建概念之間的關係，再核對。翌日或幾天後，他會再次嘗試；容易忘的內容提早回來，已能穩定完成的內容拉長間隔。將提取練習分散進行有研究支持，但故事中的具體日程，是他依表現調整的安排。[4]

第一天，他畫出的圖缺了一條重要關係。第二天，他雖能背出名詞，卻仍說不清楚那條關係。

他沒有把兩種錯誤一概寫成「沒背熟」。前一種需要補回知識連結；後一種需要重新讀解釋、研究例子，再用自己的話推導。

如果合上書後幾乎完全空白，他會回去補例子，或把材料切小，給自己一個有限提示，再逐步撤去提示。這使困難變得可處理。

他也不只做名詞卡。有些題要求解釋，有些要求判斷反例，有些要求指出實驗設計的漏洞。他希望未來完成哪種任務，就安排相應的練習。

每次作答前，他先估計自己有多大把握；完成後再核對。他發現，自己對熟悉措辭特別有信心，對換了說法的同一概念卻容易失手。於是，他加入不同措辭與陌生案例。

幾週後，他不看書也能恢復一些概念關係。隔了一段時間，表現仍能保留。這些改變，才給了他「確實學到一些東西」的證據。

他同時發現，學習也會留下錯誤：自己曾把「測驗總是更好」背得非常牢。經驗造成的持久改變，還需要檢查是否正確、是否有用。

**第五週，他開始練習抽象，卻差點把共同點看得太大。**

林澄把三件事並排寫下來：看著課本覺得懂；看老師推導覺得每一步合理；聽同學解釋時一直點頭。

他起初概括為：「被動學習沒有用。」但馬上想到反例：讀得仔細、邊讀邊預測的人，也可能學得很好；完全沒有基礎的人，更需要先接觸解釋。

他把抽象改小：「在這三個情況中，外部材料都提供了不少線索。我需要檢查，撤去線索後，自己能否重建必要內容。」

這個抽象省略了課本、黑板與同學聲音的差異，保留了「線索是否存在」與「能否獨立產生答案」的關係。但他把它標為需要檢查的共同結構，沒有因此斷定三種失敗一定來自同一機制。

接著，他刻意找兩類案例：內容不同但關係相近的，以及表面相近但關鍵條件不同的。

他將這個方法用在研究閱讀上：比較兩篇研究操弄了什麼、測量了什麼、排除了什麼解釋。案例比較如何幫助抽取共同結構與遷移，也有實驗研究；例如，談判學習研究發現，明確比較兩個案例能比各自研究案例更有幫助。[5]

他的抽象能力，表現在兩個方向：能從例子提出較一般的關係，也能用新例子與反例修訂那個關係。

**第六週，他第一次把方法用到新地方，也第一次遇到套用失敗。**

林澄要做口頭報告，便把提取練習用在準備上。他關掉投影片，試著回答「這項研究要解決什麼問題」，再請同學提出沒有排練過的追問。

這是一次遷移：原來在閱讀中練習的獨立提取，被調整成口頭說明與回答問題。他還要額外練習組織語句、控制時間和回應聽眾。

順利了一次，他便把同樣方法搬到一篇統計方法很難的論文上。讀完第一頁就合上，腦中一片空白。

他原本以為這表示自己還不夠努力。回頭檢查後，發現自己連兩個統計概念都沒弄懂，根本無法建立完整解釋。

他先補基礎、讀一個完整例題，再嘗試完成部分步驟，最後才獨立說明。

這次失敗迫使他補上一條使用條件：「提取練習要建立在至少已有某些可提取內容的基礎上。新任務還可能要求額外的知識與技能。」

遷移因此包含辨認、對應與調整。知道一個方法，還需要學會判斷何時用、用在哪一部分，以及何時先做別的事。

**第八週，他的研究小組遇到一個比讀論文更難的問題。**

小組準備設計一套給新生使用的複習活動。林澄提議加入閉書作答。許晴沉默，阿澤說：「我們沒有那麼多時間。」

林澄心裡冒出一句：「他們只想省事。」他正要反駁，想起自己筆記上那三欄：觀察、解釋、尚未確定。

他把目前真正知道的事情寫清楚：「許晴暫時沒回應；阿澤說時間不足。」至於不重視學習，只是他的推測。

他問許晴：「你對這個安排有什麼顧慮？」

許晴說，她擔心輪流公開回答會讓不熟悉內容的人難堪。阿澤則說，他晚上要兼職，不能每次留下來排練。

林澄覆述：「你在意的是活動怎樣讓人願意參與；你需要的是能在固定時間內完成的安排。我有沒有理解錯？」

兩人又修正了幾個細節。他這才發現，把自己的偏好放進別人的處境，仍可能漏掉對方真正重視的事。相關實驗也提醒，單靠想像他人視角未必提高準確度；直接交談取得資訊，在研究中能改善判斷。[6]

他們把活動改為先各自寫答案，再自願討論；準備工作拆成可以分別完成的部分。林澄沒有因此認為自己已看透兩位同學。他把這些說法當成目前較有根據的理解，留意後續行動是否相符。

接著，他又發現一個集體層面的原因：他們一直以為作業主要評分標準是投影片是否完整漂亮，所以討論時總先刪掉可能暴露疑問、打亂流程的活動。

核對評分要求後，他們發現，研究設計與推論品質同樣重要。他們重新分工，約定在採用方案前，每個人先寫下一個疑問。

林澄第一次清楚看見，集體行為需要同時考察成員的想法、時間限制、發言方式、分工與共同理解的規則。單用一個人的性格，解釋不了整個小組為什麼如此運作。

**第十週，他們把知識放進一個需要真正取捨的任務。**

他們希望複習活動能幫助初學者在一週後解釋概念，並判斷陌生例子；活動時間必須控制在二十分鐘內。

林澄把問題拆成兩部分：「讓概念記得住」與「讓人知道何時適用」。如果只測能否背定義，第二部分就會被漏掉。

他們製作兩個版本，請幾位自願參加的同學試用。共同閱讀內容相同，一個版本安排重讀，另一個安排回想與核對；總時間盡量相同。使用不同材料時，也交換材料與版本的搭配，避免把某篇較容易的效果誤當成方法效果。

許晴提醒：「回想版本還加入核對，所以這只能比較整套活動，不能把任何差異全算成提取本身的效果。」

他們先訂好判斷標準：一週後能否說明概念、能否分類新例子、能否解釋分類理由。作答記錄去掉版本標示，再按共同標準評閱。

試用後，有人更能說出定義，仍然分不清某些例子。林澄的第一個反應是增加測驗次數。但逐題查看後，他們發現，一些人把兩個相近概念混在一起。

於是，他們加入一對容易混淆的案例，要求參加者說明差別，再試一次。這項修改來自具體錯誤，而不是單純加強原本的方法。

小組把結果寫成「這次試用看見的問題與下一步」，沒有宣稱證明普遍規律。參加者少、材料有限，也沒有正式研究所需的完整控制，這些資料主要幫助他們改進活動。

對林澄而言，解決問題現在包含一整段工作：界定目標，處理限制，提出方案，讓方案接受檢查，再根據結果修改。學理能指引設計，實際執行仍會帶來新問題。

**第十三週，他重新拿出最初那句「我到底有沒有理解」。**

這時，他已經看見，答不出題目可能有不同來源。

有時是不知道詞義；有時是無法提取已有內容；有時是記得各個概念，卻沒有建立關係；有時是關係明白了，仍認不出新情境；也可能是題目含糊，或時間不夠。

他把幾種可能與可觀察表現、下一步放在一起：

| 看見的表現 | 值得檢查的可能原因 | 下一步 |
| --- | --- | --- |
| 連題目的詞義都說不清 | 基礎概念不足 | 回到定義、例子與鄰近概念 |
| 無提示時想不起，有提示後能說明 | 提取可能有困難 | 練習不同線索下的回想，再逐步減少提示 |
| 能背定義，判斷例子常錯 | 概念關係或邊界不清 | 比較正例、反例與容易混淆的案例 |
| 在熟悉題型會用，換情境失手 | 結構辨認或遷移不足 | 寫出新舊情境的對應與差異 |
| 分開問能答，題目合起來就錯 | 整合、任務負荷或策略可能有問題 | 拆步驟、用紙筆保留中間結果，再逐步整合 |

他在表下補上：「這些是診斷線索，不是一對一的確診規則。同一表現可能有多種原因。」

周老師問：「你現在會怎樣說，自己找到了這個問題的本質？」

林澄想了一會兒：「我會先問，我們要解釋哪一種失敗。然後找出最能解釋這次失敗、也能被檢查的關鍵關係。改變那個條件後，結果有沒有按預期改變？」

「那『本質的本質』呢？」

「是再追問，我憑什麼把它看得比其他因素重要。例如，它是否是定義上不可少的條件，還是因果上有作用的條件。這兩種理由要分開。」

他拿自己作例子：「問什麼算學習，會涉及經驗造成相對持久改變的判準。問我這次為什麼學不會，則要調查具體過程。兩個問題需要不同回答。」

這是他目前採用的工作方法。它讓「看透本質」有了可以檢查的內容，也留下修正的空間。

**學期最後一週，他檢查的內容，比一個分數多了一些。**

林澄請老師出幾道沒有練過的題，也保留一部分內容，隔一週再測。他按最初的目標，檢查自己能否解釋關係、判斷邊界、分析研究設計，以及提出合理的下一步。

他比開學時能完成更多任務，也比較知道何時需要查資料。但在比較兩個陌生理論時，他仍漏掉一個關鍵差別。

他把那道題留下來，沒有用熟悉題目的進步取代它。下一輪練習，便從這個差別開始。

周老師問：「你覺得自己的能力改變在哪裡？」

林澄翻開筆記。起初，他只記錄讀了多少頁。現在，他可以找到一串具體紀錄：某個預測怎樣出錯；哪個例子使他修改定義；哪一次對話推翻了他對同學的猜測；哪個練習改善了特定任務的表現。

他說：「我在這個領域裡，多了一些可以穩定完成的事，也更能找出下一步要學什麼。至於換到其他領域能帶過去多少，還要重新檢查。」

他也開始注意自己的思維過程：比較案例、區分概念、提出假設、推導預測、搜尋證據、修訂判斷。以前被他統稱為「想一想」的活動，現在可以拆開觀察與練習。

假期開始，他翻開語言理解的新章節。第一頁沒有抄滿定義。他先寫下一個問題：「人在什麼條件下，會把同一句話理解成不同意思？」再列出目前知道的、缺少的，以及需要什麼例子才能分清幾種解釋。

這一次，他已有一套可以開始工作的方式。

若將故事對回前面的概念，可以用下面這張表檢查自己是否看見它們的差別。

| 概念 | 故事中可以看見的動作 | 你可以仿照的練習 |
| --- | --- | --- |
| 本質 | 區分學習的判準與某次失敗的原因 | 先寫清楚是在問「是什麼」還是「為什麼」 |
| 本質的本質 | 檢查把某因素視為關鍵的理由 | 寫出判準、替代解釋，以及會推翻判斷的證據 |
| 知識 | 將結論連到研究設計、結果與限制 | 每個重要主張都附上根據與適用條件 |
| 學習 | 隔一段時間後，認識與表現仍有改變 | 做延後檢查，同時尋找留下的誤解 |
| 理解 | 解釋關係，推導變化，辨認反例 | 對概念做「解釋、變式、邊界」三種檢查 |
| 抽象 | 從不同場景抽取線索與獨立作答的關係 | 比較例子，保留關鍵差異，再找反例 |
| 遷移 | 把回想練習調整為口頭報告準備 | 列出新舊任務的共同結構與新增要求 |
| 能力 | 在不同題目、不同時間下較穩定地完成任務 | 檢查成功是否可重複，以及依賴哪些條件 |
| 思維 | 比較、假設、推論與修訂 | 把一次判斷的中間步驟寫出來 |
| 問題 | 將「學不好」改成具體的表現差距 | 寫下現況、目標、限制、未知與驗收方式 |
| 學習能力 | 找前置缺口，選方法，再依表現調整 | 每週說明下週改什麼，以及改動的根據 |
| 理解能力 | 分辨卡在詞義、關係、證據或邊界 | 對同一概念用文字、例子與推論互相檢查 |
| 理解規律的能力 | 發現測量時間改變了方法效果的比較 | 每條規律都追問條件、測量與反例 |
| 理解他人與集體 | 區分觀察與推測，查問關切，檢查規則 | 先覆述對方的意思，再核實限制與決策過程 |
| 抽象能力 | 用新例子和反例修訂一般關係 | 從具體往一般走，再回到具體驗證 |
| 解決問題 | 設計活動，試用，根據錯誤修改 | 選一個低成本、能帶來資訊的下一步 |
| 解決問題的能力 | 反覆完成界定、診斷、行動與檢查 | 留下決策、預期、結果與修改紀錄 |
| 看透本質的能力 | 找出有證據支持、能指引下一步的關鍵解釋 | 比較多個解釋，測試關鍵條件，保留不確定性 |

你可以從認知心理學的一個小問題開始，例如「為什麼看著答案覺得懂，關掉後卻說不出來？」本週先做以下一輪：

1. 寫下自己的解釋與把握程度，留下原稿。
2. 找一份可靠教材，讀到足以說明相關概念；遇到前置缺口就補。
3. 關掉資料，解釋概念，提出一個例子與一個反例，再核對。
4. 隔一天用不同措辭重答，並分析一個新案例。
5. 對照最初的解釋，寫出「我改了哪個判斷、根據是什麼、下一步還缺什麼」。

日誌可以只有五行：今天的問題；原來的判斷；我做的檢查；結果使我修改了什麼；下次要做的具體動作。下一週，從最後一行開始。
