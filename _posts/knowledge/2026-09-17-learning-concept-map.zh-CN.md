## 一個相連的模型

```text
Cognitive supports ── 促成／限制 ──┐
                                     │
Knowledge + conceptual model ────────┼─> Understanding ability
                                     │       ├─ 解釋
                                     │       ├─ 預測改變的個案
                                     │       ├─ 應用／遷移
                                     │       └─ 診斷錯誤並修正假設
                                     │
Purposeful practice + feedback ─ 建立 ─┘
                 │
                 └─> 在界定條件下可靠的表現 = Mastery
                         ├─ 辨認
                         ├─ 解釋
                         ├─ 引導式應用
                         ├─ 獨立熟練
                         ├─ 遷移／彈性掌握
                         └─ 創造／教學
```

## 概念及其連結

### 1. 認知支援

**注意力（attention）**、**工作記憶（working memory）**和**執行控制／自我調節（executive control / self-regulation）**協助學習者聚焦、在腦中保留條件、計劃、監察和轉換策略。它們影響學習者處理和表達概念的難易度。

它們是**支援**，不是理解的證明。強記憶或專注可以和只會回憶定義同時存在。

### 2. 知識與概念模型

事實、詞彙、例子、關係和機制，構成學習者建立**概念模型（conceptual model）**（又稱心理表徵）的材料。薄弱或不完整的模型會導致遺漏條件、不正確的因果推論和薄弱的遷移。

### 3. 理解能力

理解由使用模型而非單純重複資訊來顯示。目前的工作測試是：

1. **解釋**一個關係或機制。
2. **預測**條件改變時有甚麼改變。
3. **應用／遷移**該關係到一個新個案。
4. 出現錯誤或反證後，**診斷和修正**一個假設。

這使理解成為儲存知識與表現之間的橋樑。

### 4. 掌握

掌握是在某類已界定任務中的**可靠、獨立且適當靈活的表現**。它通常依賴理解，但也需要練習、程序流暢性、回饋和修正。

學習者可以理解一項原理，卻仍未掌握它：若表現緩慢、不一致、依賴提示，或只限於一個熟悉例子，便是如此。

### 5. 掌握層級

| 層次 | 核心證據 |
|---|---|
| 辨認 | 識別單字、規則、方法或例子。 |
| 理解／解釋 | 解釋主要關係或理由。 |
| 引導式應用 | 使用模型、提示或完成示例來運用概念。 |
| 獨立熟練 | 不用提示，準確且重複地完成典型任務。 |
| 遷移／彈性掌握 | 調整概念到陌生、改變或複雜情況。 |
| 創造／教學 | 診斷錯誤、比較方法、改善做法，並教導概念。 |

### 6. 證據標準

不要從自信或一次答對推斷層級。檢查：

- **準確性（accuracy）：** 結果正確嗎？
- **穩定性（stability）：** 可重複嗎？
- **獨立性（independence）：** 需要提示或筆記嗎？
- **遷移（transfer）：** 改變情況後仍成立嗎？
- **反思（reflection）：** 能找出並修正相關錯誤嗎？

### 7. 刻意練習循環

`目標 → 診斷 → 窄練習 → 嘗試 → 回饋 → 反思 → 下一個練習 → 複習`

此循環同時改善學習者的模型和表現的可靠性。回饋揭示最早失敗的一步；有針對性的練習再強化一個特定的薄弱環節。

## 診斷問題

學習任務表現不佳時，分開考慮可能原因：

1. 是否缺少必要的**知識、詞彙或概念模型**？
2. **注意力、工作記憶或自我調節**是否過載？
3. 學習者是否處於低於任務要求的**掌握層級**？
4. 是否把實際上會變的條件或因果變項當成固定？
5. 哪一個最小練習可區分這些解釋？
