## 0. 30 秒快速重拾：整張地圖在說甚麼？

```text
認知支援（處理資訊的條件）
          +
知識 + 概念模型（你知道甚麼，以及它們如何連結）
          +
練習 + 回饋（如何令弱點變強）
          ↓
理解（解釋、預測、應用、修訂）
          ↓
掌握（在已界定任務中可靠、獨立、靈活的表現）
          ↓
檢查證據：正確？穩定？無提示？可遷移？能修正錯誤？
```

> **認知支援提供思考空間；知識和模型告訴你如何思考；練習和回饋提高準確性；理解讓你能解釋、推論和使用；掌握讓你能可靠地表現。**

---

# 區塊 A：認知支援：思考的工作環境

## A1. 它們是甚麼？

**認知支援（cognitive supports）**是幫助你處理資訊的能力或條件；它們本身不是你理解內容的證明。

| 概念 | 白話描述 | 在學習中的角色 |
|---|---|---|
| **注意力（attention）** | 把注意指向重要資訊 | 減少分心，協助你跟隨步驟 |
| **工作記憶（working memory）** | 暫時保留和操作資訊 | 比較條件並進行多步推理 |
| **自我調節／執行控制（self-regulation / executive control）** | 管理自己的學習過程 | 計畫、監察、停止無效方法並改變策略 |

## A2. 日常例子

> 相同淨力推動兩輛手推車。A 較輕，B 的質量是 A 的兩倍。哪一輛有較大的加速度？

1. **注意力：** 留意「相同淨力」這個條件；不要假設「較重」代表「較小的力」。
2. **工作記憶：** 保留 `a = F/m`、`F` 固定，以及 `m` 改變這些資訊。
3. **自我調節：** 如不確定，暫停、重寫關係，並檢查是否遺漏條件。

這些行動令推理成為可能，但不保證你理解牛頓第二定律。

## A3. 常見混淆

> 「我很能專注，記憶力也好，所以我一定理解得很好。」

注意力和記憶有助理解，但**本身不是理解的證據**。

- **A** 很快背出 `F = ma` 並記得其定義。
- **B** 的記憶力一般，卻解釋在淨力不變時，質量加倍會令加速度減半；如摩擦力改變，則必須重新考慮淨力。

**B 對該主題有較強的理解證據。** A 展現的是記憶與專注支援。這個小案例無法為任何一人的整體智力排名。

## A4. 何時使用這個區塊

當你想到「我見過這個，但一做題就卡住」、「我忘記長題目的開頭」、「我跳過了條件」，或「被打斷後我做不到」時，檢查認知支援。

> 我是缺少概念模型，還是任務負荷壓倒了我的工作記憶或注意力？

# 區塊 B：知識 + 概念模型：你腦中可用的地圖

## B1. 知識不是概念模型

- **知識：** 事實、詞彙、公式、例子和規則。
- **概念模型（conceptual model）：** 把它們連結起來的結構：甚麼影響甚麼、在甚麼條件下影響，以及為甚麼。

詞彙、公式和規則是地圖上的地名；概念模型則是到達目的地所需的道路、方向、地形和關係。

## B2. 供應與價格

> 「供應較低代表價格較高。」

這是一項知識，但可能過於粗略。較可用的模型是：價格同時受供應和需求影響；供應減少通常會推高價格，但需求急跌可能阻止這個結果。

這加入了一個關鍵變數（**需求**）、條件性語言（**通常、如果、未必**），以及用來預測新案例的結構。

## B3. 心智表徵

**心智表徵（mental representation）**是對一個情況經壓縮、組織後的地圖。初學者可能看見「供應、需求、價格、庫存、買家」。有模型的人可能看見「供應和需求都會改變，所以要分別考慮它們的方向」。它透過針對性例子、回饋、比較和修訂建立，而不是神秘的天賦。

## B4. 何時使用這個區塊

當你能背定義卻看不出題目在問甚麼、把改了措辭的題目當成新知識、只記得答案，或把反例當作推翻規則而非揭示遺漏條件時，模型可能很弱。

> 我是缺少事實，還是缺少把事實連結起來的因果／條件模型？

# 區塊 C：理解能力：模型能否被使用？

## C1. 最簡單的定義

**理解（understanding）**不只是覺得某個解釋合理，或重複一項定義；它是使用模型處理改變。

```text
解釋 → 預測 → 應用／遷移 → 診斷 → 修訂
```

## C2. 學習時間與成績

### 1. 解釋

「讀得愈久，成績愈好」不一定是解釋，因為它沒有給出機制或條件。較好的解釋是：額外的*有效*時間可能透過練習、提取和回饋改善表現；同時，方法、休息、先備知識、注意力和與評估的一致性也很重要。

### 2. 預測

如果多出兩小時只是重讀、沒有提取練習，且極度疲倦，成績不一定會改善；額外時間可能不會轉化為有效學習。

### 3. 應用／遷移

看更多教學影片不一定能改善程式設計。實作、錯誤、回饋，以及之後獨立完成小任務，比單純觀看時間更重要。

### 4. 診斷

如果兩星期後表現仍未改善，問問：方法是否配合目標、練習是否仍只是閱讀、難度是否改變、睡眠或注意力是否改變，以及是否檢查了延遲提取。

### 5. 修訂

把「只要花更多時間，我就應該進步」改為：「當方法有效、能夠專注、材料配合評估，並且有回饋和複習時，額外時間較可能改善表現。」

## C3. 快速檢查

> 如果我只能回答熟悉例子，我可能只有回憶或有引導的應用。如果條件改變後，我仍能解釋、預測和修訂，我就有較強的理解證據。

# 區塊 D：刻意練習：把知道變成做到

## D1. 為何重複本身不足夠

重複可以變成：相同題型 → 熟悉格式 → 相同動作 → 不知道錯誤出在哪裡。它可以產生熟悉感，卻沒有建立更好的模型或遷移。

**刻意／有目的的練習（deliberate / purposeful practice）**每次針對一個特定弱點，需要專注，接收回饋，然後修訂。

## D2. 小案例：區分理解和掌握

「我想理解學習理論」這個目標太模糊，無法練習。一項狹窄的練習是：閱讀四個案例，判斷每個案例是否展現理解、掌握、有證據支持的最高層級，以及為何較高層級尚未得到證明。

如果你直接把十條正確的標準題分類為遷移，回饋應找出最早的失敗：它們可能共享同一熟悉格式，且沒有顯示條件改變或方法選擇。這些證據支持的是**獨立熟練（independent proficiency）**，不是**遷移（transfer）**。

下一個練習只比較：A，十條無提示的相同類型問題；B，一個要求獨立選擇方法並說明條件的陌生情境。

## D3. 循環

```text
目標 → 診斷 → 狹窄練習 → 嘗試 → 回饋 → 反思 → 下一個練習 → 回顧
```

回饋識別最早失敗的步驟。反思區分知識、條件、策略和認知負荷。延遲回顧可避免把熟悉感誤認為學習。

---

# 區塊 E：掌握：甚麼是真正的掌握？

## E1. 不只是一個正確答案

在清楚界定的任務範圍內，**掌握（mastery）**是指能在需要時**準確**、**一致**、**獨立**且**靈活**地表現。一個正確答案至多是一項正面證據。

## E2. 例子：*maintain*

| 情況 | 它代表甚麼 |
|---|---|
| 你辨認出 *maintain* 大約是「保持」 | 辨識 |
| 你說「把某物維持在某個水平或狀態」 | 理解／解釋 |
| 你在提示下完成 *maintain a healthy lifestyle* | 有引導的應用 |
| 你在電郵中自然寫出 *maintain service quality* | 獨立熟練 |
| 你在新句子中區分 *maintain*、*sustain* 和 *preserve* | 遷移 |
| 你解釋搭配、語氣和常見誤用 | 創作／教學 |

## E3. 掌握有範圍

不要抽象地說：「我已掌握英文。」例如，應說：「我能在一般工作電郵中獨立且準確地使用這組詞；在正式談判或文學寫作中，我仍沒有足夠的遷移證據。」

> 掌握的是哪項任務、在甚麼條件下？

---

# 區塊 F：掌握層級：從接觸到教學

| 層級 | 意義 | 例子：因果主張 |
|---|---|---|
| 1. **辨識（Recognition）** | 能辨認，但未必能使用 | 你辨認出「相關不等於因果」 |
| 2. **解釋（Explanation）** | 能說明含義和理由 | 解釋第三個因素可能造成相關性 |
| 3. **有引導的應用（Guided application）** | 在提示下使用 | 被提示後找出混雜因素 |
| 4. **獨立熟練（Independent proficiency）** | 獨立而可靠地完成一般任務 | 在熟悉日常主張中找出遺漏條件 |
| 5. **遷移／彈性掌握（Transfer / flexible mastery）** | 在改變的脈絡或任務中使用 | 在健康、經濟和工作決策中選擇因果分析 |
| 6. **創作／教學（Creation / teaching）** | 比較、改善和教導 | 設計小型實驗並診斷一項論證 |

第 2 層表示你能談論因果關係。第 4 層表示你會獨立尋找條件、變數、比較組和證據限制。第 4 層適用於熟悉的問題類型；當措辭、脈絡和方法選擇改變時，第 5 層仍然有效。

# 區塊 G：證據準則：別被「我感覺自己懂」欺騙

| 準則 | 問題 | 例子 |
|---|---|---|
| **準確性（Accuracy）** | 它正確嗎？ | 力不變時，質量加倍會令加速度減半 |
| **穩定性（Stability）** | 你能再做到嗎？ | 兩日後你能解答數字改變的題目 |
| **獨立性（Independence）** | 沒有提示也能做到嗎？ | 沒有提示下寫出 `a = F/m` |
| **遷移（Transfer）** | 能在新脈絡做到嗎？ | 把條件分析遷移至供應、需求或學習成果 |
| **反思（Reflection）** | 能找出並修正錯誤嗎？ | 你發現自己混淆施加的力與淨力，並作出修正 |

如果你先說：「更多學習時間不保證更高成績；方法、休息、規劃和複習也很重要」，這是一個好開始。可能已有準確性，但穩定性、獨立性、遷移和反思仍要測試。記錄為：「已展現辨認部分條件的能力；穩定性、獨立性和遷移仍待測試。」

# 區塊 H：用地圖診斷卡住的學習問題

## H1. Python：閱讀時理解，卻無法寫出來

> 觀看教學影片時，你理解 `for loop`，但編寫計算購物車總額的程式時卻卡住。

1. **認知支援：** 工作記憶是否超載？把輸入、迴圈、累加器和輸出寫在紙上；一次處理一個部分。
2. **知識／模型：** 你知道語法，卻不知道每次迭代如何改變總額嗎？手動追蹤 `total = 0 → 10 → 25 → 33`。
3. **理解：** 你能預測省略 `total = 0` 或把累加放到迴圈外會怎樣嗎？先預測，再執行程式。
4. **掌握層級：** 跟隨教學影片屬於有引導的應用；在無協助下寫出一般的總額程式可能是獨立熟練；設計平均值、分類總額和折扣則開始展現遷移。
5. **下一項狹窄練習：** 不看筆記，寫一個把 `[10, 15, 8]` 變成總額的迴圈，然後用一句話解釋每次迭代改變了甚麼。

# 一頁回顧卡

> **支援**有助處理資訊 → **模型**有助理解關係 → **理解**讓你能解釋、預測、應用和修訂 → **練習 + 回饋**令表現可靠 → **掌握**是在已界定條件下可靠、獨立、靈活的表現。

卡住時，問：

1. 我缺少內容或模型，還是認知負荷太高？
2. 我只是辨認或背誦，還是能解釋和預測？
3. 我只能跟隨例子，還是能獨立完成？
4. 脈絡改變時，我能遷移嗎？
5. 出錯後，我能找出失敗的假設或步驟嗎？
